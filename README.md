# Lista de Presença - Treinamento Git e GitHub

Este arquivo é destinado à prática de comandos básicos do Git (add, commit, push, pull).

## Instruções para os alunos

1. Sincronize o repositório local com o remoto (`git pull`).
2. Edite este arquivo e adicione seu Nome e sua Distribuição Linux favorita em um dos espaços vazios abaixo.
3. Salve o arquivo.
4. Adicione as mudanças ao *stage* e crie um *commit* com uma mensagem descritiva.
5. Envie as mudanças para o repositório remoto (`git push`).
